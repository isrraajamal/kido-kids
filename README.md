# 🧸 Kido Kids — Children's Fashion & Lifestyle E-Commerce

A modern, responsive, and luxury children's apparel e-commerce web application crafted with boutique Scandinavian aesthetics, buttery-smooth interactions, and mobile-first usability.

## ✨ Key Features & Highlights

- **Boutique Scandinavian Design**: Warm ivory glassmorphism, organic pastel badges, and high-resolution children's editorial imagery.
- **Flawless Responsiveness**: Custom responsive offcanvas drawer navigation activating dynamically at screens `< 1160px` with an ergonomic thumb-zone action bar.
- **Haute-Couture Frosted Hero Card**: Optical glass depth with `backdrop-filter: blur(32px)`, animated live beacon badge, side-by-side flex CTAs, and authentic social proof avatar stack (`+10k Happy Families`).
- **Full E-Commerce Journey**:
  - 🏠 **Home (`index.html`)**: Panoramic hero, trust pillars, curated category grid, bestsellers carousel, lookbook banner, and customer testimonials.
  - 🛍️ **Shop / Catalog (`shop.html`)**: Product catalog with responsive filters, category pills, and sort options.
  - 👗 **Product Details (`product-details.html`)**: High-res image gallery, interactive size selector, color swatches, stock indicator, and customer reviews.
  - 🛒 **Cart (`cart.html`)**: Dedicated cart management with real-time quantity adjustments, free shipping progress bar, promo code engine, and order summary.
  - 💳 **Checkout (`checkout.html`)**: Streamlined multi-step checkout with address inputs, delivery options, and secure payment toggles.
  - ❤️ **Wishlist (`wishlist.html`)**: Saved favorites with 1-click "Move to Cart" and persistent counter.
  - 📖 **About Us (`about.html`)**: Brand story, sustainable organic materials promise, and team values.
  - 📬 **Contact (`contact.html`)**: Direct customer care form, FAQ accordion, and store locator.
  - 👤 **Account / Login (`login.html`)**: Clean authentication and personalized customer dashboard.

## 🛠️ Built With

- **HTML5**: Semantic markup structured for accessibility and SEO.
- **CSS3 / Vanilla Design Tokens**: Custom design system, CSS variables, glassmorphism, and responsive media queries.
- **JavaScript (ES6+)**: Custom dynamic state management, offcanvas DOM synchronization, cart & wishlist counters, and interactive micro-animations.
- **Libraries**:
  - [Bootstrap 5](https://getbootstrap.com/) (Grid & Offcanvas primitives)
  - [Swiper.js](https://swiperjs.com/) & [Owl Carousel](https://owlcarousel2.github.io/OwlCarousel2/) (Smooth image sliders)

## 🚀 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/isrraajamal/kido-kids.git
   cd kido-kids
   ```

2. **Open in your browser:**
   - Simply double-click `index.html` to open it in any modern browser.
   - Or run a local lightweight server:
     ```bash
     npx serve .
     ```
